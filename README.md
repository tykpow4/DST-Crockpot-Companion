# Instructions
1. Subscribe to the "DST Crockpot Companion" in the Steam Workshop for Don't Starve Together. Enable it in-game.
2. Download the dst-helper.exe file from GitHub and place it in a folder by itself anywhere you want.  You can pin the executable to the start menu or taskbar since you will launch this every time you play. Once Don't Starve Together is open, you can launch dst-helper.exe: it will be a little carrot in the system tray. Click the carrot and select 'Open Crockpot Solver'.
3. Press F4 in-game whenever you want the mod to assess your inventory and send it to the browser tool.  The dst-helper.exe will shut down automatically when the game closes.
