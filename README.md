# Instructions
1. Subscribe to the "[DST Crockpot Companion](https://steamcommunity.com/sharedfiles/filedetails/?id=YOUR_WORKSHOP_ID)" in the Steam Workshop for Don't Starve Together. Enable this client mod in-game.
2. Download DST-Crockpot-Companion.zip from GitHub, extract, and place the folder containing dst-helper.exe anywhere you want (it generates log files so leave the exe in that empty folder).  You can pin the executable to the start menu since you will launch this every time you play. Once Don't Starve Together is open, you can launch dst-helper.exe: it will be a little carrot in the system tray. Click the carrot and select 'Open Crockpot Solver'.
3. Press F4 in-game whenever you want the mod to assess your inventory and send it to the browser tool.  The dst-helper.exe will shut down automatically when the game closes.
